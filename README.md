# card-pio.
Cardapio Digital para Mostra Cultural 2026 MedioTec SENAC Recife

## Criação do app
* Passo1: Criar o projeto
```
npm create @vite-pwa/pwa@latest
```
* Passo2: Aceitar o pacote PWA
* Passo3: Escrever o nome do projeto (não colocar espaço ou caracter especial)
* Passo4: Selecionar React como ferramenta
* Passo5: Selecionar JavaScript como linguagem
* Passo6: Aceitar valores padrão de PWA Name, Short Name, Description e Theme Color
* Passo7: Escolher a estratégia generateSW
* Passo8: Escolher Prompt for update como comportamento
* Passo9: Optar por não escolher as últimas configurações do Create (Estudar)

## Como dar o commit
* Obs.: usar algum padrão de commit (Commit patterns)
* git status (verificar o estado do git)
* git add . (adiciona todos os arquivos da raiz)
* git commit -m "TITULO-DO-COMMIT" (salvando a atualização com o nome)
* git push (empurrar a atualização)
* git restore --staged . (cancelar a atualização)
